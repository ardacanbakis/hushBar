# CLAUDE.md

## What this is

**HushBar** — a lightweight macOS menu bar app that mutes/unmutes the system
microphone **globally** (every app at once) via CoreAudio. Menu-bar-only agent
(`LSUIElement`), no Dock icon, no main window. It toggles a hardware device flag
and never opens an audio stream, so it does not record.

Inspired by getmicdrop.com. The directory is named `mcDrop` for historical
reasons but the product/target is **HushBar** (`hushBar`).

## Build / run (on the Mac)

The `.xcodeproj` is git-ignored and generated by **XcodeGen** from `project.yml`.

```sh
brew install xcodegen
xcodegen generate     # creates hushBar.xcodeproj
open hushBar.xcodeproj
```

**Re-run `xcodegen generate` whenever `project.yml` changes OR a source file is
added/removed/renamed** — otherwise Xcode won't see new files. This has bitten us
before (AppSettings.swift, BrandIcons.swift).

When giving the user terminal commands, **never include inline `# comments`** —
their zsh executes the comment text literally.

## Architecture

AppKit agent app; SwiftUI only for the Preferences window. Source in
`Sources/hushBar/`:

- **AppDelegate.swift** — `@main`, sets `.accessory` activation policy, requests
  mic permission, wires up the controllers, hosts the Preferences window.
- **MicMuteController.swift** — the heart. CoreAudio muting + listeners.
- **StatusItemController.swift** — `NSStatusItem`; left-click toggles,
  right-click/control-click opens the `NSMenu`. Subscribes to
  `settings.objectWillChange` to re-render live. Must inherit `NSObject`
  (required for `NSMenuDelegate`).
- **PillRenderer.swift** — draws the menu bar image per state/style.
- **AppSettings.swift** — `@Published` settings persisted in `UserDefaults`;
  `PillStyle` enum (`toggleSwitch` / `pill`). `AppSettings.shared` singleton.
- **HotKeyManager.swift** — global hotkey via the **KeyboardShortcuts** SPM
  package (Carbon-backed, no Accessibility permission). Default ⇧⌘M.
- **LaunchAtLogin.swift** — `SMAppService.mainApp` (macOS 13+).
- **PreferencesView.swift** — SwiftUI `TabView`: General / Style / About. About
  tab has social links + an animated `DancingName`.
- **BrandIcons.swift** — hand-built SwiftUI vector brand marks (no external asset
  fetch in this env).

`Support/Info.plist`, `Support/hushBar.entitlements`. Target settings live in
`project.yml`, not the (generated) xcodeproj.

## How muting actually works (hard-won knowledge)

`MicMuteController` resolves the default input device
(`kAudioHardwarePropertyDefaultInputDevice`) and applies mute across **multiple
candidate elements** (master 0 + channels 1, 2, + detected channels), because the
built-in mic exposes `kAudioDevicePropertyMute` on individual channels, not the
master. Fallbacks in order: hardware mute flag → input volume to 0 (saved/restored)
→ global-scope mute/volume. After writing, it **reads back the real state**
(`readMuted`) rather than trusting the write.

Listeners keep the UI honest: one on the default-input-device change (re-applies
intent to a new mic), one on the device's mute property (reflects external
changes).

### Gotchas discovered
- **App Sandbox virtualizes the device writes** → they don't affect real hardware.
  Sandbox is therefore **OFF** (removed from `project.yml` + entitlements) for
  Homebrew/Developer ID builds. Re-enable `com.apple.security.app-sandbox` only
  when switching to App Store distribution.
- **Microphone (TCC) permission is required** for the writes to hit real hardware,
  even though we never capture. Requested via `AVCaptureDevice.requestAccess`.
- **Only one mic-mute app can run at a time.** MicDrop (and similar) register their
  own property listener and immediately re-assert their flag whenever ours changes
  — a "last writer wins" race they win. If muting "doesn't work," check for a
  competing app first. This was the root cause of a long debugging session.

## Distribution paths

- **DMG + GitHub Releases**: Archive in Xcode → sign Developer ID → notarize →
  package with `create-dmg` → upload to GitHub Releases. Users drag to
  `/Applications`.
- **Homebrew Cask**: create `ardacanbakis/homebrew-tap` repo, add
  `Casks/hushbar.rb` pointing at the GitHub Release DMG. Users run
  `brew install --cask ardacanbakis/tap/hushbar`.
- **App Store (later)**: re-enable app-sandbox in `project.yml` entitlements, switch
  to App Store provisioning.
